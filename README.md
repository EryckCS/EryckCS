## Projeto em destaque

### [Mini-RAG da documentação HTTPX](https://github.com/EryckCS/desafio-rag-eryck-kayck)

Sistema local de recuperação de informações sobre a documentação do HTTPX.

- Recupera trechos relevantes de arquivos Markdown.
- Usa embeddings locais com Ollama.
- Armazena vetores no ChromaDB.
- Exibe fontes, metadados e ranking dos resultados.
- Possui testes automatizados e geração opcional de resposta.

**Stack:** Python · LangChain · Ollama · ChromaDB · RAG
